## 📖 About

**DigiTools** is a modern e-commerce web application where users can browse, manage, and purchase premium digital tools. The app features a fully functional shopping cart with real-time price updates, making the shopping experience smooth and intuitive.

---

## ✨ Features

### 🛒 Cart Functionality *(Main Attraction)*
- **Add to Cart** — Add any product to the cart with a single click
- **Remove from Cart** — Delete individual items from the cart instantly
- **Checkout** — Complete the purchase flow with a checkout summary
- **Live Price Update** — Cart total updates in real-time using React state management as items are added or removed

### 🎨 UI & UX
- Fully **responsive** design — works on mobile, tablet, and desktop
- Clean and modern interface with a **purple/violet** color theme
- Smooth **hover animations** and transitions
- Toast **notifications** for user feedback (add, remove, checkout actions)

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or above)
- npm or yarn

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/your-username/digitools.git
cd digitools
```

2. **Install dependencies**
```bash
npm install
```

3. **Start the development server**
```bash
npm run dev
```

4. **Open in browser**
```
http://localhost:5173
```
